# 💡 Bloquinho de Ideias

> Um espaço pessoal para guardar, organizar e transformar ideias em projetos reais.

![Status](https://img.shields.io/badge/status-em%20constante%20evolução-blue)

---

## 📌 Sobre o Projeto

O **Bloquinho de Ideias** nasceu para organizar pensamentos, conceitos e possíveis projetos.

Muitas ideias acabam se perdendo por falta de organização. Este projeto funciona como um mural digital onde cada ideia possui:

- Nome da ideia
- Categoria
- Descrição
- Objetivo
- Tecnologias possíveis
- Status
- Próximos passos

---

## 🎯 Objetivo

Criar uma ferramenta simples, bonita e intuitiva para:

✨ Registrar ideias rapidamente  
✨ Organizar projetos futuros  
✨ Visualizar possibilidades  
✨ Acompanhar evolução das ideias  
✨ Transformar pensamentos em ações

---

# 🗂️ Categorias

As ideias podem ser separadas em:

- 🎮 Jogos
- 💻 Desenvolvimento
- 🤖 Inteligência Artificial
- 🏥 Saúde
- 🌱 Sustentabilidade
- 📚 Educação
- 🚀 Startups
- 🎨 Design
- 🔬 Pesquisa

# 📊 Status das Ideias

🟣 Ideia inicial

🟢 Finalizado  
⚫ Arquivado

# 🧠 Como adicionar novas ideias

No arquivo HTML basta copiar o modelo:

```html
<div class="idea-card">
    <span class="category">🎮 Jogos</span>

    <h3>Nome da Ideia</h3>

    <p>
        Descrição rápida da ideia.
    </p>

    <ul>
        <li><strong>Objetivo:</strong> Criar algo...</li>
        <li><strong>Tecnologias:</strong> React, JS...</li>
        <li><strong>Status:</strong> Ideia inicial</li>
    </ul>

</div>
